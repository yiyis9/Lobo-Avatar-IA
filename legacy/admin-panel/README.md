# Proyecto Laravel conservado

Este directorio se conserva como referencia histórica y no forma parte de la ejecución actual de Lobo UPVT. No iniciar su servidor ni usar sus vistas: el panel activo es HTML, CSS y JavaScript servido por FastAPI.

Para iniciar el sistema vigente, sigue las instrucciones de `../backend/README.md`. El panel está disponible en `http://127.0.0.1:8000/panel/` cuando FastAPI está ejecutándose.
